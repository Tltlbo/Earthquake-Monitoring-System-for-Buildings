# STM32 구간 기반 진동 감지 구현

## 변경 범위

- 계산 모듈: `hardware/earthquake_detection/Core/Inc/vibration_detector.h`.
- `main.c`: 기존 MPU6050 읽기 함수를 재사용하고, 약 10ms 주기로 수집한다. 기존 명령 수신과 서보 로직은 유지한다.
- `esp.c`: AT 응답 대기 루프에서 센서 수집 훅을 호출한다. 대기 제한은 실제 경과 시간으로 계산한다.
- `SQLClient/central_client.c`: 선택적으로 추가된 구간 정보를 읽어 기존 가속도 점수 대신 사용한다. 중계 서버, DB 스키마, Bluetooth 메시지는 변경하지 않는다.

## 계산 및 초기화

전원을 켠 후 서보 초기 동작이 끝나면 센서를 정지시켜 둔다. 연속 100개 샘플의 축별 평균으로 중력과 설치 오프셋을 포함한 기준값을 구한다. 이어서 최근 20개 샘플의 기준값 대비 편차로 축별 최대–최소 차이와 RMS를 계산한다. 축별 결과 중 가장 큰 P2P와 가장 큰 RMS를 보고한다. 두 최대값은 서로 다른 축에서 나올 수 있다.

20개는 10ms 목표 주기에서 약 200ms 구간이다(첫 샘플과 마지막 샘플 사이의 시간은 약 190ms). 새 샘플마다 가장 오래된 값을 교체한다. 30ms를 넘는 수집 공백은 구간을 무효화한다. 초기 보정 중 공백이 생기면 보정도 다시 시작한다.

P2P 2000 raw count 이상 **또는** RMS 700 raw count 이상이면 이상 진동 후보다. 이 수치는 예시 설정이며 현장 검증값이 아니다. 소프트웨어 FIR/IIR과 상보 필터는 추가하지 않았다. 고정 기준값을 사용하므로 설치 방향 변경이나 지속적인 기울기도 RMS 이상으로 판단될 수 있다. 이 기능만으로 지진을 확정하지 않는다.

## 전송 및 호환성

기존 형식 뒤에 네 필드를 추가한다:

```text
[PJS_SQL]SENSOR@AX@AY@AZ@SHOCK@P2P@RMS@ABNORMAL@VALID\n
```

P2P/RMS는 반올림한 raw count 정수다. ABNORMAL은 0/1, VALID는 보정 및 구간 계산 완료 여부다. VALID=0 또는 기존 형식이면 관제 클라이언트는 기존 순간 가속도 판정으로 돌아간다. VALID=1이면 ABNORMAL=1에 가속도 점수 4점을 부여하고, 순간 가속도 점수를 중복해서 더하지 않는다. 영상/충격 점수와 최종 관제 단계 기준은 그대로 유지한다.

정상/이상 변화는 최대 200ms마다 전송하고, 같은 상태는 1초 간격으로 보고한다. 전송 사이에 발생한 짧은 이상은 보류 상태로 저장해 다음 보고에 포함한다. 실제 읽기 성공이 최근 30ms 이내일 때만 보고하여 센서 장애를 오래된 값으로 숨기지 않는다. 수집은 전송 대기 중에도 계속하지만 메시지는 전송 시작 전의 구간 결과를 사용한다.

## 남은 제약

- 협력형 폴링이므로 100Hz 고정 주기는 보장하지 않는다. UART 송신, 디버그 출력, I²C 대기 및 기존 명령 처리에서 공백이 생길 수 있다. 엄밀한 실시간 수집은 타이머/DMA/RTOS 등 별도 구조가 필요하다.
- 기존 `esp_send_data()`의 반환형이 void여서 전송 성공 확인/재시도는 추가하지 않았다. 보고된 상태는 전송 시도 기준이다. 네트워크 오류 중 이벤트 전달은 보장하지 않는다.
- MPU6050의 측정 범위, 내부 DLPF 및 출력 주기 설정은 기존 설정을 유지했다. 반복해서 같은 내부 샘플을 읽지 않는지 보드에서 확인해야 한다.
- 기존 TCP 중계 서버의 패킷 분할/합침 문제는 수정하지 않았다.
- DB 및 Bluetooth에는 기존 순간 가속도와 최종 단계만 전달된다. 구간 지표는 관제 로그에 표시하며 DB 저장 필드는 추가하지 않았다.

## 검증

독립 C 테스트는 정지/중력 제거, 초기 구간 채움, 양·음 진동, 슬라이딩 구간 복구, P2P 단독/RMS 단독 임계값, 정수 극값, 시간 공백, tick wraparound, 보정 중 공백을 확인한다.

```sh
cc -std=c11 -Wall -Wextra -Werror \
  -Ihardware/earthquake_detection/Core/Inc \
  tests/vibration_detector_test.c -lm -o vibration_detector_test
./vibration_detector_test
```

STM32CubeIDE에서는 헤더 기반 모듈이므로 별도 소스 등록 없이 기존 프로젝트를 빌드할 수 있다. 플래시 업로드 전 임계값 튜닝과 부하 중 샘플 간격 측정이 필요하다.

개발 PC에서는 MSVC C11 `/W4 /WX`로 계산 모듈 테스트를 컴파일하고 실행했다. STM32 툴체인이 없고 WSL이 실행되지 않아 펌웨어 전체 및 Linux 관제 클라이언트 빌드, 실제 보드/네트워크 통합 테스트는 완료하지 못했다.
