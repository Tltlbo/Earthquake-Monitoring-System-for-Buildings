# 센서 트러블슈팅 발표 그림

발표 순서: 중계 서버 통신 부하, 1초 주기의 첫 대응, 순간 취득의 미탐, STM32 내부 계산과 이벤트 전송 개선안.

그림은 내장 ImageGen으로 생성한 개념도다. 실제 프로젝트 장치 사진이나 성능 증거가 아니다. 그래프는 PowerPoint에서 편집 가능한 설명용 가상 데이터다.

## 프롬프트 요약

- `relay-load.png`: 흰 배경의 3D 기술 삽화. 왼쪽 센서와 MCU, 중앙 중계 서버에 몰리는 주황색 패킷, 오른쪽 관제 화면. navy/teal/amber 색상. 글자와 로고 제외.
- `snapshot.png`: 순간 취득을 설명하는 센서·MCU와 흔들리는 콘크리트 받침. 관측 사이의 움직임 표현. 글자·카메라·그래프 제외.
- `local-compute.png`: 보드 내부의 계산과 적은 이벤트 패킷으로 연결한 MCU, 중계 서버, 관제 화면. 같은 색상, 글자와 로고 제외.

발표 그림과 기존 슬라이드는 2026-10-11 구현 전 개선안을 설명하는 역사 자료다. 현재 적용 범위는 [구현 문서](../vibration-detector-implementation.md)를 따른다. 서버 부하와 미탐의 정확한 원인·개선 효과는 실측으로 확인해야 한다.
